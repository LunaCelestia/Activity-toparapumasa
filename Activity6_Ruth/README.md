# A Letter for Nay — beginner website project

A responsive dark-academia appreciation-letter website made with plain HTML, CSS, and JavaScript. The three photos you shared are included, and background music has been removed.

## Files

- `index.html` — the page structure and your Taglish letter
- `style.css` — colors, typography, envelope animation, and responsive layout
- `script.js` — envelope interaction and surprise message
- `photos/memory-1.jpg` — table selfie
- `photos/memory-2.jpg` — outdoor photo
- `photos/memory-3.jpg` — group photo

## Run it in VS Code

1. Download and unzip this project.
2. Open VS Code.
3. Choose **File → Open Folder…** and select `nay-appreciation-website`.
4. Install the **Live Server** extension if needed.
5. Right-click `index.html` and choose **Open with Live Server**.
6. Click the envelope to reveal the letter, then scroll to the memories and final surprise.

You can also double-click `index.html` to open it in a browser, but Live Server is better while editing.

## Change the photos or letter

The three included photos are in the `photos` folder. To replace one, keep the same filenames (`memory-1.jpg`, `memory-2.jpg`, `memory-3.jpg`). Edit the letter and captions directly in `index.html`.

## Publish it online with GitHub Pages

1. Create or sign in to a GitHub account.
2. Create a repository (for example, `letter-for-nay`).
3. Upload `index.html`, `style.css`, `script.js`, and the `photos` folder.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and the `/ (root)` folder, then click **Save**.
7. Wait for GitHub Pages to publish the site. The Pages screen will show the website URL.

The published website can be viewed by anyone with the link. Since the letter and photos are personal, share the public link thoughtfully.
